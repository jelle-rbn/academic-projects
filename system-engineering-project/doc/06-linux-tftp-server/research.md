# Research - Linux TFTP Server

As I never set up a TFTP server, I began the exploration by refreshing my knowledge of of what TFTP is and how it works.
Next, I researched guides and documentation for setting up a TFTP server on an AlmaLinux / RHEL system.
Finally, I investigated how to test a TFTP server as effectively and completely as possible.
